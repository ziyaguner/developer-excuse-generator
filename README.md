> **"No Regrets Engine"** — Sorumluluk almak istemeyen kıdemli yazılımcılar için dünya standartlarında bir bahane üretim merkezi.

Bu proje, modern web teknolojilerinin (React, Framer Motion, Web Audio API, Canvas) sınırlarını zorlayan, hem görsel hem de teknik bir portfolyo şaheseridir.

## ✨ Öne Çıkan Özellikler
- 🚀 **60FPS Performans**: GPU optimize edilmiş animasyonlar ve `requestAnimationFrame` tabanlı Canvas arka planı.
- 🎨 **Yaratıcı UI**: 3D Parallax tilt efekti, CRT tarama çizgileri ve dinamik "Matrix Digital Rain" motoru.
- ♿ **Erişilebilirlik**: Tam klavye navigasyonu (`Space`/`Enter`), ARIA-live desteği ve yüksek görünürlüklü odak stilleri.
- 🔥 **Aşırı Isınma Emniyeti**: Buton spam'lemeye karşı koruma sağlayan termal throttling simülasyonu.
- 📱 **PWA Desteği**: Mobil cihazlara uygulama olarak yüklenebilir, standalone çalışma modu.
- 🔊 **Web Audio API**: Dışarıdan dosya yüklemeden, gerçek zamanlı sentezlenen sibernetik ses motoru.

## 🚀 Yerel Kurulum
1. Repoyu klonlayın: `git clone ...`
2. Bağımlılıkları yükleyin: `npm install`
3. Motoru ateşleyin: `npm run dev`

## 🕹️ Gizli Özellikler (Easter Eggs)
- Klavyeden ardışık olarak **"BUG"** yazın ve sistemin "Kırmızı Alarm" moduna geçişini izleyin.
- Generate butonuna çok hızlı basarsanız, makinenin **"Aşırı Isınma"** uyarısı vererek kendisini soğumaya almasına şahit olun.
